# Hood Valley

### Dig deep. Mine daily. Earn $VALLEY.

Hood Valley is an on-chain mining game on **Robinhood Chain**, built around a collection of **3,333 Miner NFTs**. Holders send their Miners to work every day, mine **$VALLEY**, and take part in raffles and holder rewards across seasons.

## How It Works

Each day a **12-hour mining window** opens. The loop is simple:

1. **Enter** the mining window with your Miner.
2. **Send** your Miner to work.
3. **Let it mine** while the window is open.
4. **Collect** the $VALLEY your Miner earned.

Your Miner NFT is your pass into the game. No Miner, no mining.

### Mining Rules
- Mining happens on-chain.
- A fixed amount of $VALLEY is released for mining each day (see [Daily Emission](#-daily-emission)).
- Final mechanics (reward split per Miner, limits, rarity effects) are **TBA** and will be published before users are asked to interact with the contracts.

## Daily Emission

The 70% mining allocation (7,000,000,000 $VALLEY) is released over a **6-month (180-day)** timeline.

| Metric | Amount |
|---|---|
| Total mining supply | 7,000,000,000 $VALLEY |
| Emission period | 180 days |
| **Daily mining allocation** | **~38,888,889 $VALLEY / day** |
| Per Miner (if all 3,333 mined every day) | ~11,668 $VALLEY / day |

The per-Miner figure is a theoretical maximum average. Actual rewards depend on how many Miners participate each day and the final game mechanics.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/<your-org>/hood-valley.git
cd hood-valley

# Install dependencies
npm install

# Copy environment variables
cp .env.example .env

# Run locally
npm run dev
```
